## Ordre de dépôt recommandé

1. **Choisir le dispositif** (voir `FINANCEMENT.md` §10) — commencer par l'ADIR
   ou la French Tech La Réunion pour être orienté vers le bon guichet.
2. **Obtenir le règlement exact** (taux, plafond, éligibilité du statut).
3. **Adapter la synthèse** au formulaire (`synthese-depot.md`).
4. **Signer la lettre d'intention** avec le client pilote.
5. **Compléter le budget** avec les devis réels (`budget-previsionnel.xlsx`,
   cellules bleues).
6. **Déposer** le dossier + pièces.

## Points de vigilance

- Le **statut juridique** détermine l'éligibilité : certains dispositifs exigent
  une société (SASU/EURL), d'autres acceptent la micro-entreprise. Vérifier avant.
- Le **taux de subvention** (60-80%) dépend du dispositif et du type de dépense
  (investissement vs fonctionnement). Adapter `budget-previsionnel.xlsx`.
- La **lettre d'intention** ne vaut pas engagement financier — c'est une preuve
  de demande du marché, attendue par la plupart des financeurs.
